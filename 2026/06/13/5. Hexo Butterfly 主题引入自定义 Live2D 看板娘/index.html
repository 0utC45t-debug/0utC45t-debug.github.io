05.Hexo Butterfly 主题引入自定义 Live2D 看板娘

发表于2026-06-13|更新于2026-10-14|技术教程
|总字数:2k|阅读时长:7分钟|浏览量:

一、前言

这篇文章记录如何在 Hexo Butterfly 主题中接入 moc3 格式（Cubism 3/4） 的 Live2D 模型。不同插件支持的模型版本不同；本文使用 live2d-widget-v3，并把模型文件放在站点的 source 目录中。

本教程采用“核心库从 CDN 加载、模型资源由博客本地提供”的方式。模型文件较大，首次打开时需要下载；CDN 或模型路径不可用时，看板娘也会无法加载。

通过本文，你将实现以下效果：

  1. 加载新版模型：使用 .moc3 和 .model3.json 文件。
  2. 丰富的交互体验：看板娘不仅会跟随鼠标转动头部和眼睛，还支持鼠标拖拽、点击触发动作。
  3. 多功能工具栏：自带一言、截图、切换表情、隐藏看板娘等实用按钮。
  4. 本地托管模型：模型随站点一起生成和部署，方便管理路径和版本。

二、 准备工作

1. 准备模型文件

确保你有权在网站上使用该模型，并准备好模型所引用的所有文件。常见文件包括：

  • xxx.model3.json（模型主文件）
  • xxx.moc3（模型核心数据）
  • xxx.physics3.json（物理效果文件）
  • xxx.exp3.json（表情，可选）
  • xxx.motion3.json（动作，可选）
  • 模型引用的纹理图片和其他配置文件

2. 确认博客环境

八、动作、表情与常见问题

1. 模型太大或太小

修改 source/Resources/model/yumi/config.json 中的 scale 值：

  • 太大：调小（如 0.1、0.15）
  • 太小：调大（如 0.2、0.3）

2. 模型位置不对

修改 config.json 中的 translate：

  • x：正值向右移，负值向左移
  • y：正值向下移，负值向上移

3. 看板娘不出现

  • 检查浏览器控制台（F12）是否有报错
  • 确认 source/js/live2d-widget-v3.js 文件后缀是 .js 而不是 .js.txt
  • 按 Ctrl + F5 强制刷新浏览器缓存

Idle 用于待机动作，TapBody 用于点击模型时触发的动作。表情和动作文件名必须与磁盘上的文件名完全一致（大小写也要一致）。如果点击动作只应播放一次，确认对应 motion 文件的 Meta.Loop 为 false；需要循环的待机动作则设为 true。

工具栏配置中要保留 express 表情按钮，模型配置里也必须登记至少一个表情。动作和表情仍不生效时，打开浏览器开发者工具的 Network 面板，检查 .exp3.json、.motion3.json 是否请求成功，再检查控制台里的 JSON 解析错误。

本博客的 yumi 模型已按此方式登记 17 个表情，以 tear.motion3.json 作为待机动作，并在点击模型时播放一次 wave.motion3.json。
