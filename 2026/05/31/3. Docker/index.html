03.Docker 入门教程

发表于2026-05-31|更新于2026-10-14|技术教程
|总字数:1.4k|阅读时长:4分钟|浏览量:

这篇文章记录我在 Windows + WSL 2 上安装 Docker Desktop 后的验证过程，并补上最常用的容器命令和 Compose 入门示例。Docker Desktop 的界面和版本会更新，命令行概念相对稳定；遇到差异时以当前官方文档为准。

一、我的安装环境

以下是我记录时使用的版本，不代表现在的最新版：

组件 版本
Windows 11 Insider Preview 26200.8457（Canary）
WSL Ubuntu 24.04.3 LTS（WSL 2）
Docker Desktop 4.43.2
Docker Engine 28.3.2

安装 Docker Desktop 后，首次启动时按向导完成设置，并在 Settings 中启用所需的 WSL 发行版集成。Docker Desktop 的 Dashboard 可以查看容器、镜像、卷和日志。

二、先认识三个概念

名称 可以先这样理解
镜像（image） 创建容器时使用的应用模板，例如 nginx:alpine
容器（container） 镜像启动后的运行实例，可以启动、停止和删除
卷（volume） 独立于容器生命周期保存的数据，适合放需要保留的文件

容器被删除后，写在容器自身可写层里的数据通常也会一并丢失；需要长期保存的数据应放进卷或绑定挂载目录。

六、日常排查顺序

  1. docker version：确认客户端和 Server 都能显示。
  2. docker ps -a：确认容器是否启动或已经退出。
  3. docker logs 容器名：查看应用报错和启动日志。
  4. 检查端口映射：宿主机端口可能已被其他程序占用。
  5. 检查数据位置：容器删除后仍需保留的内容应放进卷或绑定挂载目录。

小结

Docker 的基本工作流可以记成：准备镜像、启动容器、映射端口、查看日志；需要保存数据时挂载卷，需要复现项目配置时使用 Compose。先用 hello-world 和 Nginx 做小实验，再逐步尝试自己的应用会更容易定位问题。
